# RobotsTxt

A MediaWiki extension that serves `/robots.txt` from a wiki page (`MediaWiki:Robots.txt`), with the correct `text/plain` content type and sensible generated defaults.

**Status: work in progress, not ready for general use.** Documentation will be written once the features are stable.

Licensed under GPL-2.0-or-later. Requires MediaWiki 1.43 or later and PHP 8.1 or later.
